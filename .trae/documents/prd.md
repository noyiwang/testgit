# 产品需求文档 - STUDIO NOVA 创意工作室官网

## 1. 产品概述

STUDIO NOVA 是一个高端创意设计工作室的品牌展示网站，通过大胆的视觉设计和流畅的交互体验，展示工作室的作品集、服务理念和团队实力，吸引潜在客户并建立专业品牌形象。
- 目标用户：品牌方、企业决策者、创意行业从业者、潜在合作伙伴
- 核心价值：通过独特的视觉语言传达工作室的创意能力，建立高端专业的品牌认知

## 2. 核心功能

### 2.1 功能模块
1. **首页**：Hero 主视觉区、导航栏、滚动视差效果
2. **作品展示区**：精选项目网格、项目详情弹窗、悬停交互
3. **服务区**：核心业务展示、服务流程
4. **关于我们**：工作室介绍、团队数据、理念阐述
5. **联系区域**：联系表单、联系方式、CTA 召唤

### 2.2 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页 | Hero 主视觉 | 大尺寸排版动画、滚动触发入场效果、鼠标跟随光标 |
| 首页 | 导航栏 | 透明悬浮导航、滚动时样式变化、移动端汉堡菜单 |
| 作品展示 | 项目网格 | 瀑布流/网格布局、悬停图片放大、分类标签筛选 |
| 作品展示 | 项目详情 | 点击项目卡片展开详情面板、项目信息展示、相关链接 |
| 服务区 | 服务卡片 | 悬停动效、图标动画、横向滚动列表（移动端） |
| 关于我们 | 数据展示 | 数字滚动动画、团队照片墙、时间线 |
| 联系 | 表单交互 | 输入框聚焦效果、提交动画、表单验证 |
| 全站 | 交互效果 | 平滑滚动、页面转场、视差滚动、自定义光标 |

## 3. 核心流程

用户访问网站后，首先被 Hero 区域的视觉冲击吸引，通过滚动浏览各个区域：
- 浏览精选作品 → 点击感兴趣的项目查看详情 → 了解服务内容 → 建立品牌认知 → 发起联系咨询

```mermaid
    G --> "H[滚动到联系区域]"
    H --> "I[填写联系表单/查看联系方式]"

```

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深邃炭黑 (#0A0A0A) 为底色，搭配暖米色 (#F5F0E8) 文字，强调色为电光蓝 (#00D4FF)
- **辅助色**：柔粉色 (#FF6B9D)、亮橙色 (#FF8C42) 作为点缀
- **按钮风格**：几何感强、无圆角或极小圆角、悬停时填充反色、带微妙边框
- **字体选择**：
  - 标题：Playfair Display（优雅衬线体，营造高端感）
  - 正文：Space Grotesk（现代几何无衬线，科技感与可读性平衡）
  - 辅助文字：JetBrains Mono（等宽字体，用于标签和数据）
- **布局风格**：桌面端采用不对称网格、打破常规对齐、大量留白；元素有层叠和偏移
- **图标风格**：线性简洁图标，Lucide React 图标库
- **视觉特效**：噪点纹理叠加、渐变光影、粗边框分割线、几何装饰元素

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 全局 | 背景 | 纯黑背景 + 细微噪点纹理 + 动态渐变光斑 |
| 全局 | 导航 | 左上角 Logo、右上角菜单链接、滚动时背景模糊 |
| Hero | 主标题 | 超大字号衬线字、逐字/逐行入场动画、错位排版 |
| Hero | 副标题 | 等宽字体标签、横向滚动跑马灯 |
| 作品区 | 项目卡片 | 大尺寸图片、悬停时图片缩放+文字上移、粗边框 |
| 服务区 | 服务项 | 编号标识、悬停时背景填充、箭头指示器 |
| 关于区 | 数据统计 | 大号数字、计数动画、细分割线 |
| 联系区 | CTA 按钮 | 大尺寸、填充动画、磁性跟随效果 |
| 页脚 | 信息区域 | 多列布局、大字版权声明、社交链接 |

### 4.3 响应式设计
- 桌面端优先设计（1440px+）
- 平板适配（768px-1024px）：调整网格列数、缩小字号
- 移动端适配（<768px）：单列布局、汉堡菜单、简化动画、触摸优化
- 断点：1024px、768px、480px

### 4.4 动效设计
- 页面加载：Logo 加载动画 → 内容依次入场
- 滚动触发：元素从下方淡入上移、视差速度差异
- 悬停状态：按钮填充反色、图片轻微缩放、文字颜色变化
- 自定义光标：桌面端显示大圆形光标，悬停可交互元素时变形放大
- 平滑滚动：全站使用 smooth scroll 行为
