## 1. 项目概述

### 1.1 项目背景

「码上行」是一个开源工程师的个人技术品牌，旨在通过持续输出高质量技术文章、系统化教学课程和开源项目实践，构建个人在开发者社区中的技术影响力。需要建设一个统一的个人品牌网站，整合博客、课程、开源作品等内容模块，实现技术能力的资源推广。

### 1.2 项目目标

| 目标 | 描述 | 衡量指标 |
|------|------|---------|
| 品牌展示 | 建立专业的个人技术品牌形象 | 网站月访问量、停留时长 |
| 内容分发 | 高效分发技术文章和课程内容 | 文章阅读量、课程转化率 |
| 社区连接 | 连接开发者社区，吸引关注者 | Newsletter 订阅数、GitHub Star 增长 |
| 变现支撑 | 为付费课程和技术咨询提供入口 | 课程报名量、咨询转化率 |

### 1.3 目标用户

**核心用户画像:**

- **初级/中级开发者**（25-35岁）: 希望系统学习后端开发、分布式系统、云原生技术的工程师
- **技术团队负责人**: 寻找技术方案和工具的开源项目
- **技术内容消费者**: 关注技术博客、定期阅读深度技术文章的开发者
- **潜在学员**: 有意向付费学习系统化课程的开发者

### 1.4 品牌定位

**品牌名:** 码上行（CodeWalker）  
**Slogan:** 用代码丈量世界  
**定位:** 温暖、人文、专业 — 不是冰冷的技术文档站，而是有温度的技术社区

### 2.2 首页模块

#### 功能描述

首页是品牌的第一印象，需要快速传达「码上行」的技术能力和内容方向，引导用户进入核心内容。

#### 信息架构

| 区域 | 内容 | 优先级 |
|------|------|--------|
| 顶部导航 | 品牌名 + 5 个主导航链接 + 暗色模式切换 | P0 |
| Hero 区 | 品牌标语 + 介绍语 + CTA 按钮 + 主视觉图 | P0 |
| Bento Grid | 最新博客 + 课程统计 + 开源项目 + 社区入口 | P0 |
| 精选文章 | 3 篇精选文章卡片 + 查看全部按钮 | P0 |
| 技术栈 | 编程语言/框架/工具分类展示 | P1 |
| Newsletter | 订阅入口 + 社交证明 | P1 |
| 页脚 | 品牌信息 + 快捷链接 + 社交媒体 | P0 |

#### 交互逻辑

1. **导航**: 点击导航链接跳转到对应页面（技术博客/教学课程/开源作品/关于我）
2. **Hero CTA**: "开始探索" 按钮跳转到技术博客页
3. **Bento Grid**: 最新博客卡片可点击跳转到文章详情
4. **精选文章**: "查看全部文章" 按钮跳转到博客列表页
5. **Newsletter**: 输入邮箱后点击订阅，显示订阅成功反馈

#### 设计规范

- Hero 采用非对称 60/40 布局，左侧文字右侧插图
- Bento Grid 使用 2x2 不等大网格，大卡片跨 2 行
- 配色: 奶油底色 (#FFFBF5) + 琥珀强调色 (#D4663C)
- 标题使用衬线字体 (Noto Serif SC)，正文使用无衬线字体 (Inter)

- **排序**: 默认按发布时间倒序

1. **目录导航**: 点击目录项平滑滚动到对应章节
2. **代码块**: 提供"复制代码"按钮，点击后显示"已复制"反馈

### 2.7 文章管理模块（管理后台）

#### 功能描述

文章管理是站长的私有后台，用于创建、编辑、发布和管理所有博客文章。该模块**仅站长本人可访问**，普通访客无法看到入口。

#### 权限控制

| 角色 | 权限 |
|------|------|
| 站长（码上行） | 完整 CRUD：新建、编辑、发布、归档、删除文章 |
| 普通访客 | 无任何后台入口，不可访问管理页面 |

**实现方案:**
- 管理页面路由需登录认证（推荐 Next.js Middleware + JWT）
- 或使用环境变量控制的隐藏路由 + Basic Auth
- 管理页面不出现在公开导航栏中
- 博客列表页可选提供"管理入口"链接（仅站长登录后可见）

#### 页面结构

**文章管理列表页 (admin-articles.html)**

| 区域 | 内容 | 优先级 |
|------|------|--------|
| 管理顶栏 | 品牌标记 + 锁图标 + "管理后台"标签 + 管理员头像 | P0 |
| 页面头部 | "文章管理"标题 + 文章总数 + "+ 新建文章"按钮 | P0 |
| 统计卡片 | 4 张卡片: 总文章数、已发布、草稿、本月阅读量（含趋势指标） | P0 |
| 搜索筛选栏 | 关键词搜索 + 状态筛选（全部/已发布/草稿/已归档）+ 分类下拉 + 排序下拉 | P0 |
| 文章数据表格 | 10 列: 复选框、标题(含分类标签)、状态徽章、阅读量、发布日期、操作按钮 | P0 |
| 批量操作栏 | 选中计数 + 批量发布/归档/删除 + 取消选择 | P0 |
| 分页 | "显示 1-10 / 共 N 篇" + 页码 + 上一页/下一页 | P0 |
| 快捷侧边栏 | 导入 Markdown、导出文章、最近编辑列表、写作统计 | P1 |

**文章编辑器页 (admin-editor.html)**

| 底部状态栏 | 字数/行数统计、自动保存时间、连续写作计数 | P1 |

#### 文章状态流转

```
                  ┌──────────┐
                  │   新建   │
                  └────┬─────┘
                       │
                  ┌────▼─────┐
              ┌─────│   草稿   │─────┐
              │     └────┬─────┘     │
              │          │ 发布      │ 删除
              │     ┌────▼─────┐     │
              │     │  已发布   │─────┘
              │     └────┬─────┘
              │          │ 归档
              │     ┌────▼─────┐
              └─────│  已归档   │─────┘
                    └──────────┘
```

- **草稿 → 已发布**: 点击"发布"按钮，文章对公开页面可见
- **已发布 → 草稿**: 取消发布，文章从公开页面隐藏
- **已发布/草稿 → 已归档**: 批量归档，文章仍保留但不显示在列表
- **任意状态 → 删除**: 永久删除（需二次确认弹窗）
- **定时发布**: 设置未来时间，到时自动从草稿转为已发布

#### 编辑器功能规格

**Markdown 编辑器:**
- 深色编辑区（背景色 `#2D2A26`，文字色 `#F5E6D3`）
- JetBrains Mono 等宽字体
- 行号栏（左侧，静态装饰）
- Tab 键插入 2 空格缩进
- 快捷键支持: Ctrl+B 加粗、Ctrl+I 斜体、Ctrl+S 保存

**格式化工具栏按钮:**

| 按钮 | 功能 | Markdown 语法 |

| H | 标题 | `## Heading` |

| UL | 无序列表 | `- item` |
| OL | 有序列表 | `1. item` |
| TL | 任务列表 | `- [ ] item` |
| Code | 行内代码 | `` `code` `` |
| Code Block | 代码块 | ` ```lang ` |
| Quote | 引用块 | `> text` |
| Link | 链接 | `[text](url)` |
| Image | 图片 | `![alt](url)` |
| Table | 表格 | `\| col \|` |

| 分类 | 下拉选择 | 分布式系统/前端工程/Go语言/开源实践/云原生/架构设计 |
| 标签 | 多选输入 | 支持已有标签快速选择 + 自定义新标签 |
| 封面图 | 文件上传 | 支持 JPG/PNG/WebP，建议 1200x630 |
| 摘要 | 多行文本 | 最多 200 字，用于 SEO 和文章列表展示 |
| URL 别名 | 文本输入 | 自动生成拼音/英文 slug，可手动修改 |
| 发布状态 | 单选切换 | 草稿 / 已发布 / 定时发布 |
| 定时发布 | 日期时间选择 | 仅"定时发布"状态时可见 |
| 是否置顶 | 复选框 | 置顶文章显示在博客列表顶部 |
| 允许评论 | 复选框 | 默认开启 |

**自动保存:**
- 编辑器内容每 30 秒自动保存为草稿
- 底部状态栏显示"最后保存: X 秒前自动保存"
- 防止意外丢失未发布内容

**导入/导出:**
- 导入: 支持上传 `.md` / `.markdown` 文件，自动解析标题和内容
- 导出: 支持导出单篇或全部文章为 `.md` 文件打包下载
- 导入时自动检测 Front Matter（YAML header）

#### 批量操作

| 操作 | 说明 | 二次确认 |
|------|------|---------|
| 批量发布 | 将选中的草稿文章全部发布 | 是 |
| 批量归档 | 将选中的文章全部归档 | 是 |
| 批量删除 | 永久删除选中的文章 | 是（高危操作） |

#### 移动端适配

- 文章管理列表: 表格横向滚动，侧边栏折叠至底部
- 文章编辑器: 单栏布局，底部 Tab 切换（编辑/预览/设置），工具栏横向滚动

## 3. 全局交互设计

### 3.1 导航系统

- **顶部导航栏**: 固定在页面顶部（sticky），所有页面统一
- **导航项**: 首页 / 技术博客 / 教学课程 / 开源作品 / 关于我
- **当前页标识**: 对应导航项高亮显示（琥珀色 + 底部指示线）
- **移动端**: 汉堡菜单，点击展开侧滑导航面板

### 3.2 页面导航路径（核心浏览流）

**公开页面浏览路径:**

```
首页 → 技术博客 → 文章详情
首页 → 教学课程
首页 → 开源作品
首页 → 关于我
```

所有公开页面间可通过顶部导航任意跳转，文章详情页提供"返回博客列表"按钮。

**管理后台路径（仅站长）:**

```
博客列表 → 文章管理（管理入口，登录后可见）
文章管理 → 文章编辑器（新建或编辑）
文章编辑器 → 文章管理（返回）
文章管理 → 博客列表（返回公开页面）
```

### 3.3 暗色模式

- 所有页面支持暗色模式切换
- 切换按钮位于导航栏右侧
- 使用 CSS 变量实现主题切换（`prefers-color-scheme` + 手动切换）
- 暗色模式配色: 深棕黑底 (#1A1614) + 暖灰文字 + 琥珀强调色

### 3.4 响应式断点

| 断点 | 宽度范围 | 布局策略 |
|------|---------|---------|
| 移动端 | < 640px | 单列堆叠，汉堡菜单 |
| 平板 | 640px - 1024px | 2 列网格，精简侧边栏 |
| 桌面 | > 1024px | 完整布局，侧边栏可见 |

## 6. 技术建议

### 6.1 推荐技术栈

| 层面 | 推荐 | 理由 |
|------|------|------|
| 框架 | Next.js (App Router) | SSG/SSR 支持，SEO 友好，适合内容站 |
| 样式 | Tailwind CSS | 与设计稿一致，快速实现响应式 |
| 内容管理 | MDX / Contentlayer | Markdown 写作，嵌入代码组件 |
| 部署 | Vercel | 自动部署，边缘优化，免费额度充足 |
| 评论 | Giscus | 基于 GitHub Discussions，免费且社区友好 |
| 分析 | Umami | 开源、隐私友好的网站分析 |
| 搜索 | Pagefind | 静态站内搜索，零成本 |

### 6.2 性能指标

| 指标 | 目标值 |
|------|--------|
| LCP | < 2.5s |
| FID | < 100ms |
| CLS | < 0.1 |
| Lighthouse 总分 | > 90 |

### 6.3 SEO 要求

- 每个页面设置独立的 `<title>` 和 `<meta description>`
- 文章详情页使用结构化数据 (JSON-LD: Article)
- 生成 `sitemap.xml` 和 `robots.txt`
- 图片使用 WebP 格式 + 响应式 srcset
- 预渲染关键页面（SSG）
